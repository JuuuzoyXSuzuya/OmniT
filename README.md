# OmniT — патчер TikTok с подменой региона

Android-приложение, которое берёт оригинальный APK TikTok, вшивает в него мод подмены региона,
подписывает и устанавливает. Патчинг идёт прямо на телефоне.

## Как это устроено

```
hook/   — МОД. Java-классы, которые вшиваются в TikTok
          RegionHook  — перехватчики getSimCountryIso / getNetworkOperator / Locale.getCountry и т.д.
          RegionData  — таблица 29 стран (ISO, MCC/MNC, оператор)
          RegionUi    — плавающая кнопка 🌐 слева на экране TikTok и диалог выбора страны
app/    — ПАТЧЕР. Приложение, которое ставится на телефон
          DexPatcher  — dexlib2: заменяет invoke-virtual на invoke-static RegionHook.*
          HookDex     — достаёт классы мода из собственного dex патчера и пакует их в classesN.dex
          ZipIo       — копирование APK без перепаковки + выравнивание как zipalign
          ApkSign     — подпись v2+v3 (ключ в Android Keystore)
          MainActivity — выбор файла, прогресс, установка через PackageInstaller
```

**Подмена региона находится в самом моде.** Страну выбирают в TikTok: нажмите 🌐 слева,
выберите страну, перезапустите приложение. Выбор хранится в `files/omnit_region.txt`
внутри данных TikTok. Пункт «Реальный регион» выключает подмену.

## Сборка APK патчера (без Android Studio)

Нужен аккаунт GitHub.

1. Создайте репозиторий и загрузите в него всё содержимое этой папки, включая скрытую `.github`.
   Если `.github` не загружается через веб-интерфейс, создайте файл вручную:
   *Add file → Create new file*, имя `.github/workflows/build.yml`, вставьте содержимое из архива.
2. Откройте вкладку **Actions → Build patcher APK → Run workflow**.
3. Через 3–6 минут в запуске появится артефакт **OmniT-Patcher** (внутри `app-debug.apk`).

Локально: `./gradlew assembleDebug` (JDK 17 и Android SDK 34).

## Использование

1. Установите `app-debug.apk` на телефон (Android 7+).
2. Откройте OmniT Patcher → «Выбрать файл TikTok». Подходит обычный `.apk`
   или набор `.apks` / `.xapk` / `.apkm`.
3. «Пропатчить» и подождите. На большом APK это несколько минут, приложение не сворачивайте.
4. «Установить». Если система пишет про конфликт подписи, нажмите
   «Удалить оригинальный TikTok» и установите снова. Данные оригинала при этом пропадут.

## Ограничения

- **Проект не собирался и не запускался.** В среде, где он написан, нет Android SDK и закрыт Maven.
  Проверены только `ZipIo` (тест на реальном zip: содержимое, выравнивание, удаление старых подписей)
  и синтаксис остального кода. Работа с dexlib2 и apksig не проверена. Если сборка упадёт,
  пришлите лог ошибки.
- **Проверка целостности TikTok.** Приложение перепаковано с другой подписью. Если TikTok сверяет
  подпись, оно может вылетать, не пускать в аккаунт или вести себя странно. Обхода проверки в проекте нет.
- **Регион подменяется только на уровне Java-вызовов.** Сервер определяет страну ещё и по IP,
  а нативные библиотеки TikTok могут читать данные SIM в обход этих вызовов. Для устойчивого результата,
  скорее всего, нужен ещё VPN.
- **Лимит 64K методов.** Если в dex TikTok нет места для 9 ссылок на хук-методы, этот dex останется
  без патча, и в логе будет предупреждение. Если не пропатчен ни один dex, патчер остановится с ошибкой.
- **Ключ подписи** лежит в Keystore патчера и не вынимается. Если удалить патчер или очистить его данные,
  новую версию патченного TikTok поверх старой поставить не получится, придётся удалить старую.
- Нужно много оперативной памяти: dex TikTok перезаписывается целиком, `largeHeap` включён.
- Подмена данных и модификация приложения нарушают условия использования TikTok. Аккаунт могут ограничить.
